## Modificare autonomamente

Per modificare visualmente i file effettivi, apri questa cartella come progetto in Pinegrow Web Editor. Mantieni una copia di sicurezza. Testi e immagini sono elementi HTML; il comportamento dello scorrimento resta nel file project.js. Pinegrow non è incluso né installato con questa consegna.

È presente anche l'editor sperimentale interno: aggiungi `?editor=1` all'indirizzo della pagina nell'anteprima locale. Permette correzioni a testi e layout, ma salva nel browser ed esporta JSON: NON salva direttamente i file del sito e NON pubblica le modifiche. Non usarlo come unica copia del lavoro.

I file del sito sono locali: questo ZIP non costituisce una pubblicazione online.
